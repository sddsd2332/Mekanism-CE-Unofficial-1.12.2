# Mekanism CE 示例

这里的文件是 Mekanism CE 1.12.2 的 CraftTweaker（CRT）和 GroovyScript（GRS）示例，默认不会被构建或自动加载。使用时请将对应脚本复制到整合包实例的脚本目录，并根据实际的流体名称修改注释中的占位内容。

## 目录

- `crafttweaker/`：CRT 气体注册、气体流体映射和灌注类型/物品注册。
- `groovyscript/`：GRS 气体注册、气体流体映射和上游兼容层提供的灌注注册。

## 通用注意事项

- 自定义气体必须在客户端和服务端使用完全相同的注册脚本。气体 ID 按注册顺序分配。
- 气体注册只能在预初始化阶段完成。CRT 使用 `#loader mekanism`，GRS 使用 `preInit`。
- 示例名称带有 `example` 前缀。实际整合包应使用不会与其他脚本冲突的名称。
- 将已有气体映射到其他模组的流体会改变相关配方和流体转换行为，请只在确实需要时取消对应注释。
- 本仓库新增了 CRT 的气体和灌注注册接口；GRS 的灌注接口来自其上游 Mekanism 兼容层，示例仍然可以直接使用。

更具体的复制位置和加载阶段说明见各子目录中的 `README.md`。
